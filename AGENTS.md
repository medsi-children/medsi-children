# Медси Бот: актуальная инфраструктура

- Основная ветка: `medsi-bot-main`, рабочее приложение: Timeweb App Platform 2.0 + PostgreSQL 18 + S3.
- Ветка `timeweb-next` и Cloudflare / Apps Script — **исторический путь/потенциальный источник данных для сверки**, не источник новых релизов.
- **Запрещено** отправлять изменения в бывшие Cloudflare Workers / Apps Script или включать их деплой из `timeweb-next` без отдельного согласования с оператором миграции.
- Действующий пользовательский домен уже переключён на App 2.0; не менять DNS, SSL, секреты, production-флаги, существующие данные, DB или S3 без согласованного задания.
- PostgreSQL-репозиторий и CI должны содержать только синтетические тестовые данные. Реальные отчёты, сообщения, фотографии, список пациентов, сессии, пароли, токены и дампы запрещено сохранять в Git, GitHub Actions и логах.
- Код отчётного движка использует локальную копию проверенных старых алгоритмов в `services/postgres-next/legacy-report-source`. Не удалять эти файлы и не переписывать алгоритмы без проверки паритета.
- ВАЖНО: после первичного переноса осталась несверенная дельта D1/Google за 2026-11-05. До подтверждённой сверки запрещено удалять старые данные, отключать источники, уничтожать архивные refs и rollback-инфраструктуру.
- История Git и архивные ветки не являются безопасным хранилищем секретов и медицинских данных. GitHub сейчас публичный; перед уничтожением refs проверить содержимое. Удаление branch не очищает историю.
- Перед PR: `npm run verify` и `npm run verify:postgres-next`; если меняется деплой, проверь отдельно smoke/cutover safety.
- Детали уборки: `docs/POST_CUTOVER_CLEANUP.md`.
